# Copilot 历史分页发布记录

前后端分支 `codex/copilot-history-pagination`，合入各自 `eddie`。Agent 无需更新。

恢复会话初次只加载最新 50 条，提供“加载更早消息”；错误可以重试，已有内容不清空；前插历史保留阅读位置，切换会话取消请求并丢弃迟到结果。样式遵循 WATCHALERT-DESIGN.md，frontend-design 技能用于保持现有组件一致性，不改变业务或确认流程。

接口 `sessionGet` 新增 `limit=50` 和 `before`，返回 `hasMore/nextCursor`。先发布新前端再发布新后端；旧前端无法翻阅新后端第一页之外的历史。回滚先后端再前端。新前端可读取旧响应，但旧后端仍会全量加载。

验证：19 项单元测试、类型检查、生产构建通过；11 项性能浏览器回归及 5 项 Copilot 相关流程检查通过，包含 1440px/390px、重试后阅读位置和新对话迟到响应隔离。本机 Chrome + 本地预览 + 模拟 API；不是生产后端联调，未构建/部署镜像。构建仍有原有大块警告，未通过调高阈值隐藏。

剩余：反复手动加载/连续发送会积累 DOM，尚未虚拟化；单条历史文本/证据仍可能较大；会话列表仍为最近 50 个会话。完整数据库验证与发布边界见后端 `docs/PERFORMANCE-COPILOT-HISTORY-2026-10-10.md`。
