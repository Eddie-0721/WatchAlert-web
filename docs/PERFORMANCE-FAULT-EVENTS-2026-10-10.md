# 故障中心事件读取与空闲刷新优化

日期：2026-10-10。前端基线 `0683108`；本批仅前端运行代码变更，后端仅维护记录，独立 Agent 无变更。

## 实际发现

- `AlertCurrentEvent` / `AlertHistoryEvent` 仍被故障中心详情页引用，不能视为废弃代码删除。两者在文本变化时立即读取；修改前构建的 Chrome 用例复现：打开和翻页共 2 次请求后输入 `payment`，请求总数变为 9。
- 当前事件 `isFiltering` 状态触发读取后再清零，又触发一次 effect；空页回首页也同时直接递归查询和通过分页 effect 查询。
- 先以空搜索请求、再从 URL effect 同步关键词会造成多余初始查询；历史页第一页回车只设置相同页码，可能不读取。
- 两个列表缺少请求取消和迟到结果隔离。Tabs 默认保留已访问页面，隐藏页面仍会跟随共享 URL 的搜索变化读取。
- 当前事件页有每 100ms 更新 `percent` 的循环，`percent` 未用于输出；本地浏览器时钟推进 2 秒复现 20 次新的 100ms 定时安排。它偶然带动了持续时长刷新，不能只删除循环而让时长停止更新。

## 已实施

- URL 作为搜索词和当前标签页的单一来源；带关键词打开时直接读取正确范围。输入即时显示、停止输入 300ms 后读取；回车、清空、其他筛选、分页立即执行。过滤词变化同步回第一页。
- 去掉 `isFiltering` 来回切换和空页递归读取；单一 effect 响应实际条件变化。响应只更新总数，不覆盖用户当前页码。
- 请求携带 AbortSignal，新的读取取消旧读取，筛选、隐藏、卸载使旧响应失效。取消不显示失败；真实失败有独立文案和原刷新/回车重试入口。
- 隐藏的事件标签页不读取；重新显示时使用当前 URL 和各页现存的筛选/分页刷新。不销毁其他标签页状态。
- 认领、删除和静默完成后通过最新读取函数刷新，避免异步操作完成后查询旧筛选；写操作内容、确认和权限不变。
- 持续时长改为秒级时钟，并显式传给格式化/色块计算。仅当前事件页可见、有数据且无读取错误时运行；空页和隐藏标签页停止。保留实时持续时长，未声称只更新单元格或将全部页面重渲染消除。

未增加依赖、全局缓存、页面布局改造或接口格式变更。故障中心外已完成的告警工作台/通知记录保持不变。

## 验证

- 修改前构建的两项输入合并测试均失败，实测额外请求 7 次；修改后相同输入节奏仅 1 次。
- 移除旧循环前空闲计时测试失败，实测 20 次；修改后空页该循环为 0。可见非空列表仍逐秒更新持续时长，隐藏时停止，且不因此刷新 API。
- 专项覆盖 URL 初始范围、搜索/回车/清空/输入法、筛选分页、空页回首页、失败重试、迟到结果、浏览器 XHR 取消、隐藏标签页与时长。
- 28 项单元测试、TypeScript 检查和生产构建通过；10 项专项浏览器用例连续三轮共 30 项通过。新增导航取消测试最初错误地用链接定位按钮而超时，修正定位后完整三轮重跑通过。最终构建保持不变的 294 项页面挂载、交互和性能浏览器回归全部通过，包含 320/390/700/1440px 检查；挂载检查不等于所有业务操作完整验收。
- 测试为本地 Chrome、生产构建和模拟 API；不是生产吞吐或延迟结论，也未覆盖所有操作系统输入法。原有入口和编辑器大块构建提示仍保留。

## 发布、边界与下一步

仅需构建前端镜像，可单独回滚前端。未部署生产、未发送真实通知或调用真实模型。后端 Redis 网络读取的在途取消仍受旧客户端限制，浏览器取消不等于后端所有工作即时终止。

Copilot 长会话渲染、普通告警全量缓存扫描、真实 Redis/SQL/Ingress 的容量验证及维护计划其他剩余项继续推进。当前事件每秒仍会重渲染页面，非列表的图表/通知抽屉读取本批未统一取消；不能声称全站所有请求和渲染均已优化完毕。
