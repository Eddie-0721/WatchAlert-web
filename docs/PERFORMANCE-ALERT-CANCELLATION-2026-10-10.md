# 告警列表读取取消

日期：2026-10-10。基线：`66beee2`。

## 变更

`utils/http` 的 GET 封装增加可选 AbortSignal，不改变其他调用默认行为。`api/event` 当前/历史读取透传 signal，主动取消不显示错误。告警工作台为当前/历史查询分别维护 AbortController，读取前取消上次请求，effect 清理时取消请求；仍保留请求序号防止迟到结果覆盖新视图。

筛选、搜索、分页、队列变化和卸载覆盖上述清理流程；刷新/回车重新查询复用同一取消行为。没有改动认领和静默写操作、业务状态、分页字段或页面布局。

## 验证与限制

- 25 项单元测试通过，新增 6 项覆盖查询编码、signal 透传、主动取消静默和真实错误反馈。
- TypeScript 检查与生产构建通过；已有 Monaco 等大 chunk 提示仍保留。
- 43 项浏览器检查通过：Chrome 对本地构建和模拟 API 验证 1440px/390px 的真实 XHR abort 事件，包括连续搜索、当前→历史切换、离开告警页面；验证当前/历史迟到响应不覆盖新结果且能继续刷新。并回归其他工作台流程。
- 模拟 API 浏览器检查不等同于生产后端和 Ingress 的端到端取消。后端需要配套版本才能减少取消后的后续扫描；旧 Redis v6 正在进行的网络读取仍不能通过 context 立即中断。

## 发布

合入前端 `eddie` 后构建镜像，推荐配套更新后端本批 `eddie`。无需修改配置、迁移数据库或更新独立 Agent。前后端可独立回滚，无协议格式变化。详细后端测试、基准与边界见后端仓库同名文档。
