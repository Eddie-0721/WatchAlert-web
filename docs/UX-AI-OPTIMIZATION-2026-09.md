# WatchAlert 全站 UI / UX 与 AI 优化报告

日期：2026-09-07。评估基线：前端 eddie / 7b41e9c，后端 eddie / 400adae。

## 1. 结论与范围

保留已确定的「Vercel 极简视觉 + 告警处置流程 + Copilot 工作台」方向。当前主要问题是新旧页面混用布局规则、共享样式误伤状态语义、数据展示口径不一致，以及 AI 的证据与操作流程未完全闭合。

本报告覆盖路由表全部 43 个入口（含参数化新建/编辑和兜底页）、其关联列表/详情/弹窗，以及已有 AI 后端。全量覆盖指代码与信息架构检查；浏览器验证范围单独记录，不将模拟数据验证等同生产验收。

核心用户：值班 SRE（找到问题并处置）、规则维护者（确认检测与通知是否有效）、服务负责人（查看影响和交接）、管理员（管理连接、权限和模型）。

设计标准：单一内容滚动容器；相同页边距、标题层级、按钮尺寸和表单节奏；状态色保留语义；列表先呈现位置、问题、责任和时间；未加载/失败/无数据必须分开。AI 输出和系统事实分别展示。

## 3. 已确认的跨页面问题

1. `src/index.css` 对所有 Tag 覆盖颜色，对所有主按钮覆盖黑色，对输入边框使用 `!important`：可能覆盖危险、禁用、校验错误等语义。
2. `TableWithPagination` 接收 loading、locale 但未传到 Table，loading 却传给 Pagination；查询中与空结果难以区分。
3. 新版页面自带 42px/44px padding 与最大宽度，旧版使用容器 40px，标题分别 30px/25px；切换页面发生横向节奏变化。
4. 侧栏仅按路径前缀判断，Manage 的规则编辑/模板等子页面无归属高亮。移动端直接隐藏管理入口和账号/租户操作。
5. 故障中心 CSS 全局改写所有 Tabs 的 position；CodeMirror 通用选择器为内部子节点重复加边框；旧 global.css 隐藏全站滚动条。
6. 告警页统计的是本页数据；Manage 的连接状态、通知可用与首页「所有服务正常」「Copilot 今日简报」缺少对应证据。

## 4. 统一视觉与交互规范

- 基础背景 #fafafa，内容面 #fff，正文 #18181b，辅助文字 #71717a，边框 #e4e4e7；紫色仅用于 AI 入口，红/黄/绿/蓝分别保留危险/警告/成功/信息语义。
- 标准页边距桌面 32px、窄屏 18px；页面标题 26px，正文 14px，辅助信息至少 12px。表格与指标可以使用紧凑字号，不能让关键状态成为 9px 小字。
- 普通页共享页宽、标题和顶部间距；Copilot、日历、指标编辑器保留任务所需布局。
- 主操作通常一个；次操作描边或文本；危险操作使用语义危险色。键盘焦点可见，图标按钮有名称，子页面具有导航归属。
- 统一 loading、空态、错误和重试；总数必须说明数据范围。已配置、已启用、最近检测正常是三个不同状态。
- 弹窗与抽屉共享表单规范；窄屏不隐藏关键动作与 AI 证据；宽表格在自身横向滚动。

## 5. AI 优化方案（纳入整体产品）

### 已有能力

DeepSeek 页面配置、独立 Agent 服务、Go 工具网关、当前告警/规则/静默查询、Prometheus 即时/范围查询、静默创建/修改/删除与认领的待确认操作、会话存储及工具审计。

### P0：可核对、可恢复、权限一致

- 工具成功显示「查询成功」，不能显示「结论已验证」；证据跟随对应消息，保留来源/查询时间/范围和截断说明。
- 接入已存在的会话列表/详情接口；区分能力加载失败、Agent 未启用与旧版 AI，禁止在失败时悄悄切换执行路径。
- 只读与可申请写操作文案依据后端能力动态展示，窄屏仍能查看证据和确认操作。
- 确认操作时再次验证 Agent 开关、工具权限、最新范围及生产写策略，已有预览不能越过新限制。
- Prometheus 数据源权限不能代替指标环境权限；共享数据源场景需校验表达式内每一个向量选择器的环境条件。

### P1：值班实际工作

- 从告警详情分析：解释阈值、查询指标、展示已知事实与假设，提供排查步骤。
- 指标与标签元数据发现，减少猜指标；带时间范围的历史告警工具；按环境/服务/资源/时间推荐关联告警。
- 静默预览展示当前匹配数量、目标、时限、原因及执行结果；确认时重新评估范围。
- 规则健康检查先使用确定性校验，再由 AI 解释；修改建议以差异草稿呈现。
- 模型连接测试、服务健康诊断、调用耗时/失败率/用量和反馈；日志与模型输入中的敏感数据按字段脱敏。

### P2：新增轻量业务能力

- 在现有故障中心中增加故障记录：编号、负责人、状态、关联告警、处置时间线、解决说明。配置与一次故障分开。
- 服务归属与运行手册链接，先不用完整 CMDB；由规则/服务关联文档起步，再建设检索。
- 值班交接与复盘草稿必须引用真实处置记录。
- Kubernetes 事件、日志、变更记录等外部只读 Connector 沿用网关。单 Agent 足够，不为扩展预先建设多 Agent 或工作流平台。

## 6. 执行顺序与边界

本轮先完成报告并实施第一批：共享主题语义、页面与导航一致性、表格加载/滚动、首页/Manage 状态真实性、告警列表分页与队列口径、Copilot 历史/证据/能力反馈，以及 AI 查询和确认范围加固。

规则评估遥测、模型连通性测试、完整 Manage 后端聚合、标签映射配置、故障记录和外部 Connector 属后续批次，不能在本轮交付中标为完成。

## 7. 验收

构建与针对性测试：前端生产构建；分页和导航/状态关键逻辑；后端事件队列、PromQL 范围和操作权限测试。浏览器使用隔离的本地演示 API 检查代表性页面、错误/加载/空态、长列表及移动端入口；不对生产执行写操作。

验收场景：危险按钮和校验错误仍可辨认；子页导航高亮正确；页面上下滚动不改变内容横向位置；超过 100 条告警可翻页且队列总数来自后端；无监控数据时不宣称服务正常；Copilot 证据可见、会话可恢复、权限收紧后的操作被拒绝。

最终验证记录与未完成事项见 [本批升级说明](RELEASE-2026-09.md)。本报告的路线图不等同于全部功能已实现。
